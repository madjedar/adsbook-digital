# adsbook.digital - Mobile Landing Page

صفحة هبوط مخصصة للهواتف لبيع الاشتراكات الرقمية الرسمية في الجزائر:
- **Canva Pro (3 Years)**
- **CapCut Pro (1 Month)**
- **Shahid VIP (1 Month)**
- **Google AI Pro (18 Months)**

## Features
- تصميم Mobile-First سريع بتأثيرات Cyber Glassmorphism.
- ربط فوري مع تطبيق واتساب (رقم محلي جزائري: 0770953046).
- ربط مع Make Webhook لمعالجة الطلبات تلقائياً.
- متوافق تماماً مع الاستضافة المجانية عبر GitHub Pages.
